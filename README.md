# Simple Interest Calculator

A lightweight, easy-to-use command-line utility for calculating simple interest on principal amounts over a specified period.

## Features

- **Fast Calculations**: Instantly compute simple interest and total accrued amount.
- **Zero Dependencies**: Pure Python standard library implementation.
- **Clean Interface**: Straightforward interactive prompts or command-line arguments.

## Mathematical Formula

Simple interest is calculated using the standard formula:

$$I = P \times r \times t$$

Where:
- **$I$** = Total Interest
- **$P$** = Principal Amount (initial deposit or loan amount)
- **$r$** = Annual Interest Rate (as a decimal, e.g., 5% = 0.05)
- **$t$** = Time duration (in years)

Total Amount ($A$) payable or received:
$$A = P + I$$
